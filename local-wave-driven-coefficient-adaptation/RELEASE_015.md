# Submission Release 015

> Craig W. Botnen, *Local Wave-Driven Coefficient Adaptation on Metric Networks: Short-Time Well-Posedness and Finite Propagation*.

## Reproducibility scope

The repository contains the higher-order numerical solver, controlling parameters, CSV outputs, method note, and diagnostic definitions. The first-arrival detection threshold is `1e-10`. The numerical method is illustrative and is not used to prove the analytical theorems.
